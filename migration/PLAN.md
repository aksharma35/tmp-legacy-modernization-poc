### Behaviours to preserve

**SummaryPanel**
- `$broadcast`/`$on` is a global event bus. In React, lift the shared state up and pass callbacks/props.
- `| currency:'₹'` renders the symbol, en-US thousands separators and exactly two decimals, e.g. ₹1,400.00.

**ExpenseForm**
- AngularJS form validation ($touched, $error, ng-disabled). Messages appear only after the field is left (blur).
- `$broadcast`/`$on` is a global event bus. In React, lift the shared state up and pass callbacks/props.

**ExpenseList**
- A confirmation dialog. Keep the exact same message text.
- `$broadcast`/`$on` is a global event bus. In React, lift the shared state up and pass callbacks/props.
- `| currency:'₹'` renders the symbol, en-US thousands separators and exactly two decimals, e.g. ₹1,400.00.
- `| date` parses '2026-09-02' as a LOCAL date. `new Date('2026-09-02')` is UTC and shows the previous day west of UTC.
- `| filter:query` matches case-insensitively against EVERY property (numbers included), not just the title.
- `| orderBy:'-field'` sorts descending and is stable (ties keep their original order).
