## Behaviour changes and decisions

| Field | Legacy | New | Decision | By |
|---|---|---|---|---|
| `GET /api/summary  average` | 727 | 727.2727272727273 | **keep-legacy** | Claude (build session) |
| `GET /api/summary  by_category[*].average` | 833 | 833.3333333333334 | **keep-legacy** | Claude (build session) |
| `GET /api/summary  by_category[*].share_percent` | 13.0 | 12 | **keep-legacy** | Claude (build session) |

AI explanation shown to the reviewer at decision time:

> average fields: `total / counts[cat]` and `grand_total / count` in build_summary. In Python 2, `/` between two integers truncates (2500 / 3 = 833); in Python 3 it is true division and returns 833.33.
> share_percent: `round(total * 100.0 / grand_total)`. Python 2's round() rounds .5 away from zero and returns a float (12.5 -> 13.0); Python 3 rounds .5 to the nearest even number and returns an int (12.5 -> 12).
